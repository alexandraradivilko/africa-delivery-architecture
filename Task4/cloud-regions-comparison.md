# Сравнение облачных регионов

**Дата проверки публичных сведений: 03–04.11.2026.** Это текущий справочный срез для учебного проекта, не восстановление тарифов на август. Ни одна VM не заказана; сетевые измерения из целевых стран не выполнены. SLA облака — договорное обязательство отдельной услуги при определённой конфигурации, а не доказательство доступности Africa Delivery.

Managed допускается согласно ADR-001 при согласовании отклонения от позиции CTO.

## 2. Сопоставимая стоимость и связь с TCO

Три гиперскейлера сопоставлены по VM с 2 vCPU / 8 GiB, но поколения CPU и производительность отличаются. Compute-only за 730 часов: GCP $53,81, Azure $83,95, AWS $92,71. Это не сравнение полного HA-контура. Локальные тарифы относятся к другим размерам VM и валютам: **ранжировать по ним полные контуры нельзя**. Для котировок всем поставщикам направляется одинаковая спецификация:

- два backend/worker узла по 2 vCPU / 8 GB, 730 ч/мес.; два узла PostgreSQL по 4 vCPU / 16 GB, либо эквивалентный HA PostgreSQL;
- по 200 GB persistent storage на узел БД, 100 GB объектов и 300 GB начального хранилища копий/WAL; это стартовые объёмы, проверяются по росту и удержанию 35 суток;
- HA-вход, IP, независимый witness, локальный key recovery, 100 GB/мес. межплощадочного трафика и 100 GB/мес. интернет-egress; рост WAL в нагрузочном прогоне может изменить оценку;
- вторая площадка внутри страны с гарантированной возможностью восстановления ≤60 мин, её capacity/standby/сеть, поддержка и доступы;
- отдельно VAT/прочие налоги, FX, избыточные IOPS, платные операции хранения, поддержка и время инженеров. Долгосрочные discounts и Spot не входят в базовый расчёт.

Формула месяца: `2 × VM_app + 2 × VM_db + диски + объекты/копии + LB/IP/сети + witness/ключи + DR + поддержка/налоги`. Для managed DB вместо двух VM/их дисков подставляется полный HA-тариф, чтобы не посчитать их дважды. Нельзя сравнивать single-zone managed DB с HA-парой или считать storage backups бесплатным.

Конверты из TCO: **NG $900/мес., KE $1100/мес.** для перечисленных страновых ресурсов. CDN и общий набор SaaS учитываются отдельно; итоговые фиксированные расходы $2800. Они остаются плановыми лимитами, а не полученными предложениями. При превышении на Δ месячная техника с сообщениями и резервом растёт на `1,15 × Δ`; свободный прирост до резерва — $547,83 при 20 тыс. заказов. См. [расчёт](failover-plan.md).

Оплата по счёту с отсрочкой 45 дней должна быть подтверждена до выбора. PAYG не означает доступность такой отсрочки; наличие кредитной карты, годовой предоплаты или нового штата не предполагается. Источник — артефакт 6, п. 2–5. Локальные тарифы сохраняются в исходной валюте до курса, утверждённого CFO; валютная экономия не придумывается.

## 3. Проверка задержек и пригодности

В течение 48 часов измерить DNS, TLS, HTTP RTT и полный API P50/P95/P99 из Лагоса, Найроби и Йоханнесбурга минимум по двум независимым операторам. Использовать один и тот же малый ответ, холодное/тёплое соединение, часы пик; отдельно проверить профиль мобильной сети NFR-03. Сохранить время, AS/оператора, регион/SKU и методику. Измерение из машины разработчика в другой стране не заменяет эти результаты.

Для синхронной пары БД измерить RTT между доменами отказа и задержку commit под нагрузкой 100 RPS. При непрохождении CAT-L/PAY-L сначала пересмотреть размещение пары и ёмкость; не отключать синхронность молча. До этого таблица latency годится только для отбора вариантов испытаний.

**Порядок выбора:** допустимая страна всех компонентов → независимость и RTO/RPO → цена и условия счёта → latency/эксплуатация. Для NG/KE южноафриканские регионы отсекаются первым условием текущей политики. Для будущего ZA AWS выбран предварительно; окончательный выбор может перейти к GCP/Azure по сопоставимой котировке и проверенному местному DR, без изменения бизнес-кода.
